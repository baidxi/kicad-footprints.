# KiCad Footprint Libraries

This repository contains the official KiCad footprint libraries.

**The libraries in this repository are intended to be used with KiCad version 8.**

Each footprint library is stored as a directory with the `.pretty` suffix. The footprint files are `.kicad_mod` files within.

Contribution guidelines can be found at http://kicad.org/libraries/contribute
The library convention can be found at http://kicad.org/libraries/klc/

Other KiCad library repositories are located:

* **Symbols:** https://gitlab.com/kicad/libraries/kicad-symbols
* **3D Models:** https://gitlab.com/kicad/libraries/kicad-packages3d
* **Templates:** https://gitlab.com/kicad/libraries/kicad-templates

## Building and installing

You do not have to build the libraries - they can be used directly from a checkout of this
repository by setting the `${KICADx_FOOTPRINT_DIR}` environment variable to the path of the
repository root (the directory containing this file).

If you wish to clone and use this repository for the purpose of contributing changes, this is
probably all you need to do.

However, packagers may wish to use the CMake build process to perform some additional steps,
as well as preparing the packaged files for installation in a way most suitable for KiCad to
use them:

```
mkdir build
cd build

# Set build options here
cmake [-D...] ..
cmake --build .
DESTDIR=pkg cmake --install .
```

### Stripping the 3D models

The `clean_3d_models` target removes the 3D models from footprints that do not have models
in the 3D model repository. To use this, set the `KICAD_3DMODEL_LIST_FILE` CMake variable to
the path of the 3D model list file. This file is generated by the `kicad-packages3d` repository
and is named `model_names.txt`.
